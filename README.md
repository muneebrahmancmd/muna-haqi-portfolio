# 🎨 Muna Haqi Portfolio — Muneeb Rehman

**Motion-led portfolio — Next.js 16, WebGL, Three.js & Lenis.**

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit-brightgreen?style=for-the-badge)](https://muna-haqi-portfolio.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-Repo-black?style=for-the-badge)](https://github.com/muneebrahmancmd/muna-haqi-portfolio)

Hi, I'm Muneeb Rehman — a creative developer, web designer, graphic designer and AI enthusiast from Pakistan. This portfolio is built around motion-driven WebGL scenes: a glass "hello" hero, a hyperspace "Innovate" section, and a glass footer, with live previews of my shipped projects.

> Built on the structure, WebGL scenes (glass "hello" hero, hyperspace "Innovate", glass footer), chrome and animations of the open reconstruction `MarkChu-git/haoqi-design` (a reconstruction of haoqi.design). Content, branding, links, stickers, signature and projects are Muneeb Rehman's.

## ✨ Features

- Glass "hello" WebGL hero
- Hyperspace "Innovate" section
- Live iframe previews of shipped projects with dedicated pages
- Custom stickers and signature artwork
- Smooth scrolling with Lenis
- 3D motion with Three.js and React Three Fiber
- Dark theme throughout

## 🛠️ Tech Stack

- **Next.js 16** — framework
- **React 19** — UI
- **Three.js + React Three Fiber** — 3D / WebGL
- **Motion** — animations
- **Lenis** — smooth scrolling
- **Zustand** — state
- **Tailwind CSS 4** — styling
- **TypeScript**

## 🚀 Run Locally

```sh
git clone https://github.com/muneebrahmancmd/muna-haqi-portfolio.git
cd muna-haqi-portfolio
npm install
npm run dev   # http://localhost:3000 (Node 20.9+)
```

```sh
npm run build && npm start   # production build
```
